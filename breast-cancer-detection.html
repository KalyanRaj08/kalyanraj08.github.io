Breast cancer detection

A machine learning project that tells whether a cell is malignant or benign from the cell descriptions in a dataset.

Stack
Python · pandas · NumPy · Jupyter notebook
Data
Wisconsin breast cancer dataset from Kaggle, 569 rows
Accuracy
About 97%
View on GitHub ↗ More projects

result

97%accuracy at telling malignant from benign

how it works

  1. DataThe dataset was downloaded from Kaggle. It holds descriptions of cells and whether each is malignant (cancerous) or benign (not cancerous).
  2. SplitThe 569 rows are split three ways: training, validating and testing.
  3. TrainThe model is trained with Python machine learning code.
  4. PredictAfter training, the code classifies a cell as malignant or benign with about 97% accuracy.

The .ipynb notebook is attached with the question and the answer. To run it, open it in Anaconda or Google Colab. Run the cells one by one to see each step of the machine learning code.
