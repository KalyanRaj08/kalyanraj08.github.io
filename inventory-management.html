Inventory management system

The KK Supermarket Inventory Management System, a Python console app that keeps the data of every product in the store, tells products apart by id and name, prints bills and records every sale.

Stack
Python 3.6 · JSON files
Type
Console app
Data
Products and sales stored in JSON

screens

swipe or use the arrows

what it does

  1. AccountsCreate a new account, sign in with an existing one, or delete an account.
  2. Admin toolsPassword-protected. Admins can add products, remove products, search for a product, and see the bill list of everyone who bought from the store. No two products can share an id or a name.
  3. Customer ordersA customer enters product names and quantities and gets a bill to print for their records. The app also stores every sale.
  4. SearchCustomers can search for products in the store. The stock list shows each product's number, name, availability, price, discount value in rupees and latest stock-in date, then asks for the product name to search.

It would be useful for any shop if it grew into a full application with a better user interface.

how to use it

  1. Welcome pagePress enter to start.
  2. Home pageYou need an account to get in. Press 1 if you are new to login, 2 if you already have an account, 3 to delete an account, or 4 to exit.
  3. Inventory systemAfter signing in, choose 1 for Admin, 2 for Customer order, 3 to Search for a Product, or 4 to Signout.
  4. Moving aroundEvery page has an exit option that takes you a step back. You can sign out and sign in with another account, and exit on the home page closes the app.
