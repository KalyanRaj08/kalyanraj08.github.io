origin story

It is a clone of one of my favourite simple games, Wordle, rebuilt in JavaScript with React. I was bored one weekend and planned to learn front-end JavaScript, so I ended up building this.

how it plays

  1. Pick a wordA random five-letter word is chosen from a list of 5,757 words that the browser loads from a JSON file.
  2. Type a guessType letters on the keyboard, press Backspace to delete and Enter to submit.
  3. Check the wordA word that is not in the list shakes the row, and a try is not used.
  4. Read the coloursGreen is the right letter in the right place. Yellow is a letter that is in the word elsewhere. Red is a letter that is not in the word.
  5. Six triesYou get six guesses. A winning row gets a green border.
