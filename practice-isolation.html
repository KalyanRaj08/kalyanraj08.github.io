Zoho Practice isolation

Moved Zoho Practice out of the monolithic Finance Suite into its own service, with shared services extracted to dedicated repos. No production outage.

why it was needed

The Finance Suite monolith holds 11 products, so moving a Practice build to the monolith server was slow. I analysed which code had to move, how to move it, and made the technical decisions. My manager helped plan the phases and handled approvals.

build movement, before and after

before2 weeks~500 commits, 11 products
→
after2 days~30 commits, 1 product

what I did

  1. Analysis and planWorked out which code needed to move and how, then moved it in phases planned with my manager.
  2. Shared reposClient request, task and workpaper were split into their own repos because both the monolith and the Practice app servers use them.
  3. Task on its own serverTask moved alone to an individual app server. The Practice and monolith servers trigger its actions through internal API calls.
  4. Independent build pathSet up zip creation, a zip file host, a build uploader and a testing setup for the new repo, so builds move without depending on the monolith repo.
