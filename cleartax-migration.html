the team

The team had me for the Practice side, a migration team representative, and a support person who faced the ClearTax team. I owned the Practice implementation and made the critical decisions and flows. Two junior Practice developers built on my implementations.

what was onboarded

300+accountants, one Practice org each
2,000+clients, each a Books org added as a client in Practice

how it was done

  1. Scripts for bulk creationWrote scripts to create many clients with their organisations from Zoho Practice.
  2. Queued API jobA junior developer built the multi-client creation API as a queued job that creates one client every 10 minutes. The bulk org creation API is guarded by a key, so only selected customers can use it.
  3. Working around throttlingThrottling stopped continuous org creation, so the API creates orgs 10 minutes apart. We also added an internal-only API that eases throttling a little.
  4. Script on a lab serverFor the script, we uploaded a build with very low throttling to an internal lab server and created the orgs there, with permission from the security team.
